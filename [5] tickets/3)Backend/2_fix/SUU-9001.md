# SUU-9001 fix(backend): 새 규정 버전에 색인이 없어도 질문에 답하기

> Linear 무료 한도 초과로 Linear 이슈 없이 진행한다. 번호 9001은 Linear 번호와 겹치지 않게 고른 것이다.

## 목표
서버가 켜질 때 `common_dataset_current`가 아니라 **임베딩된 청크가 있는 가장 최근 eCFR release**로 색인을 올린다.

## 배경 (실측)
- 9/29 매일 수집이 eCFR release `55214309…`(원문 9/25 기준)를 공개하고 `common_dataset_current`를 그쪽으로 옮겼다. 이 release의 `rag_chunk`는 0개다.
- 서버가 켜지면 `_load`가 청크 0개로 `load_index` → `build_keyword_search` → `BM25Okapi([])`에서 `ZeroDivisionError`를 낸다. 색인 스레드가 죽어 `/ask`·`/health`가 계속 503이다 (Render 로그 9/30 01:18 UTC).
- 색인 재생성은 일부러 사람이 하는 단계다(`1_Project_full.md` "답 직전의 사람 확인"). 그 사이에도 서버는 그 전 release(`0c2efcae…`, 임베딩 5,625개)로 답해야 한다.

## 건드릴 파일
- 고칠 것 `[3] backend/app/index.py` — `indexed_release_id(client) -> str` 추가
- 고칠 것 `[3] backend/app/main.py` — `_load`가 `common_dataset_current` 대신 `indexed_release_id(client)`를 쓴다
- 테스트(Claude가 씀) `[3] backend/tests/test_indexed_release.py` 새로, `[3] backend/tests/test_ready.py` 한 줄 추가(`main.indexed_release_id`를 바꿔 끼움)

## 안 하는 것
- 9/29 release 색인 만들기, `db-refresh.yml`·수집 파이프라인 바꾸기
- 판정서한 색인(`LETTER_RELEASE_ID`) 로직
- 청크가 있는 release가 하나도 없을 때의 처리 (지금처럼 스레드가 실패하고 503이면 된다)
- `tests/` 아래 파일 수정 (Codex 금지)

## 완료 기준 ↔ 테스트

## Codex 메모
- `indexed_release_id(client)`:
  1. `common_dataset_release`에서 `dataset = "ecfr"`, `status = "published"`인 행을 `published_at` 내림차순으로 읽는다
  2. 앞에서부터 `rag_chunk`에 `release_id = 그 release`, `index_status = "embedded"`인 행이 1개라도 있는지 본다. 예: `.select("chunk_key", count="exact").eq(...).eq(...).limit(1).execute().count`
  3. 처음 찾은 release_id를 돌려준다. 하나도 없으면 `RuntimeError`
- **dataset 필터 필수.** `rag_chunk`에는 판정서한(adi) release 청크도 있다. 테스트의 가장 최근 release는 일부러 adi다.
- 테스트의 가짜 DB(`FakeDB`)는 `table / select / eq / order(col, desc=) / limit / range / execute`만 흉내낸다. `execute()`는 `data`(limit 적용)와 `count`(limit 전 개수)를 같이 준다. `neq`·`in_`·`gt` 같은 다른 필터는 쓰지 않는다.
- `main.py`는 `from app.index import indexed_release_id, load_index`로 가져와서 `_load`에서 `indexed_release_id(client)`를 부른다. `test_ready.py`가 `main.indexed_release_id`를 바꿔 끼우기 때문에 모듈 전역 이름이어야 한다.
- `_load`의 나머지(STATE 넣는 순서, 판정서한 색인은 그 뒤)는 그대로 둔다.
- 머지 후 Render 자동 배포가 되면 `https://us-factory-compliance-service.onrender.com/health`가 200과 `0c2efcae-…`를 돌려줘야 한다.
