# SUU-295 docs(rag): summary·full에 데이터 파이프라인 절 추가

## 목표
문서 3개가 실제 자동 갱신(eCFR·FR 매일, ECHO 매주 화요일)과 맞게 틀린 곳만 고친다.

## 건드릴 파일
- 고칠 것: `[1] docs/2) db/0_Data Specification_v1.md`
  - §6 Collection 표 Cadence: eCFR `매일 03:17 UTC (자동)`, FR `매일 03:17 UTC (자동)`, ECHO `매주 화요일 05:17 UTC (자동)`, ADI + CAA는 `수동` 그대로
  - §6 "자동 일정(cron) **없음**. 사람이 돌림." → 워크플로 파일 이름(`db-refresh.yml`, `echo-refresh.yml`)과 "RAG 색인 재생성은 사람이 실행"을 한 줄씩
  - §10 표 4번 "자동 갱신 없음" 행 삭제 (뒤 번호는 그대로 둬도 됨)
- 고칠 것: `[1] docs/1) project/1_Project_full.md`
  - 204줄 "개정되면 원문을 다시 받아 적재하는 파이프라인을 만들었습니다." → "매일(ECHO는 매주) 원문을 다시 받아, 바뀌었으면 새 버전으로 적재합니다." 정도로
  - 최신성 표 ECHO 행 "매주, 정부 갱신 다음 날" → "매주 화요일 (정부는 일요일 갱신)"

## 안 하는 것
- 새 절 추가 안 함. summary·full의 `### 최신성` 절이 이미 자동 갱신을 설명한다 (사용자가 "틀린 곳만 고치기" 선택)
- 0_Project_summary.md는 틀린 곳이 없어 안 고침
- 다른 절, 숫자 수정 안 함
